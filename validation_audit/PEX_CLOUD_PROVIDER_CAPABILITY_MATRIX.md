## 1. Executive Context & Evaluation Methodology

The PeX (Payment Exception Resolution) platform requires enterprise-grade cloud capabilities to operate at institutional banking scale ($100M+ daily exception throughput, sub-second latency, zero data loss, strict segregation of duties, and zero PII leakage).

This capability matrix documents the exact technical services, features, and compliance primitives offered by **Amazon Web Services (AWS)**, **Google Cloud Platform (GCP)**, and **Microsoft Azure** across 20 Tier-1 banking requirements.

## 3. Neutrality Conclusion & Cloud Selection Guidelines

All three Tier-1 cloud providers (AWS, GCP, Azure) provide full, production-certified capabilities to fulfill all 20 PeX banking requirements. 

- **PeX Core Neutrality:** The PeX core codebase remains 100% cloud-agnostic.
- **Enterprise Deployment Decision:** The selection of target cloud provider should be determined solely by the adopting financial institution's existing enterprise landing zone, preferred identity governance (e.g. Entra ID vs AWS IAM Identity Center vs Google Cloud Identity), and existing cloud vendor agreements.
